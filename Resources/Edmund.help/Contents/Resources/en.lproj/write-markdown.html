Write Markdown

Type Markdown and Edmund formats it in place: **bold** shows as bold, # Title as a heading. The Markdown characters stay in the file. They show when the insertion point is inside the formatted text, and hide when it moves away.

To see the plain Markdown everywhere, choose View > Show Source in Editor.

Format text without typing the syntax

Select text, then choose an item from the Format menu. For example, choose Format > Font > Bold, or press Command-B. Format > Heading, Format > Alert / Callout, and Format > Bulleted List insert the matching Markdown for you.

To show these commands above the text, choose View > Show Format Bar.

What Edmund supports

Standard Markdown
Headings, emphasis, lists, checklists, links, images, block quotes, code blocks, tables, and GitHub alerts such as > [!NOTE].
Extended syntax
Front matter, ==highlight==, math in $…$ and $$…$$, %%comments%%, [[wikilinks]], #tags, footnotes, block IDs, and Obsidian callouts. Turn each one on or off in Syntax settings.
Diagrams and advanced math
Mermaid diagrams and fuller math support are extensions you download. See Extensions settings.

Add an image

Drag an image file into the document, or paste one. Edmund copies the image into a folder named after the document (for notes.md, notes.assets) and inserts a link to it. An untitled document asks you to save first, so the image has a folder to go in.

To link to an image where it is instead of copying it, hold Option as you drag it in, or click Image in the toolbar and choose Attach File. To add the Image button, choose View > Customize Toolbar.

To set an image’s width, add it after the alt text: ![photo|300](photo.png).

Work with tables

Choose Format > Table to insert one. Click a cell to edit it, and press Tab to move to the next cell. When the insertion point is in a table, a ⋯ button appears beside the row and above the column that contain the insertion point. Click one to select that whole row or column; the button widens into a tab with an arrow. To add or delete a row or column, click the arrow, or double-click the tab. To move a row or column, drag its ⋯ button. To line up the columns in the Markdown source, choose Edit > Align Table Source.
