Syntax settings

To open these settings, choose Edmund > Settings, then click Syntax.

Markdown syntax

Edmund always supports standard Markdown, GitHub tables, checklists, and GitHub alerts. Enable extended Markdown syntax (non-GFM) adds syntax from Obsidian and other editors. Turn it off to show only standard Markdown; the extended syntax then shows as plain text.

When it’s on, select or deselect each kind:

Code highlighting

Default code syntax
The language used to color a code block that doesn’t name one after its opening ```.
Available syntaxes
The languages Edmund can color. To add one, click the Add button (+) and choose a language definition file (.json). A definition with the same name as a built-in language replaces it. To remove a language you added, select it and click the Remove button (−). You can’t remove built-in languages.
