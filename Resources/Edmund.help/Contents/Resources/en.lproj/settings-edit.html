Edit settings

To open these settings, choose Edmund > Settings, then click Edit.

Indentation

Prefer using
Whether pressing Tab inserts spaces or a tab character.
Indent width
How many spaces make one level of indentation. The default is 2.
Detect indent style on document opening
When you open a document, Edmund uses the indentation the document already has, instead of the settings above. This changes only that document.

Words

Automatically close parentheses and quotes
Typing an opening bracket or quote also types the closing one.
Check spelling while typing
Underlines misspelled words. Code, links, math, and other Markdown that isn’t prose are skipped.
Check grammar while typing
Also marks grammar problems. Available when spell checking is on.

Lists

Show list indent guides
Draws a faint vertical line beside each level of a nested list.
Automatically continue lists
Pressing Return in a list starts the next item. Pressing Return on an empty item moves it out one level, or ends the list if it isn’t indented.

Characters

Show invisible characters upon selection
When you select text, faint marks show the spaces, tabs, line endings, and other hidden characters in it. Choose which kinds to show with the checkboxes below.

Lines

Show line numbers
Shows a line number beside each line of the Markdown source. Line numbers aren’t printed or exported.
Strict line breaks
On (the default): a single line break inside a paragraph doesn’t start a new line in Read, export, or print, as in standard Markdown. Off: every line break shows as a new line.

Document

Detect hard wrap pattern for lines on document opening
For documents whose paragraphs are broken into short lines at a fixed width: Edmund joins the lines when it opens the document, so paragraphs wrap to the window, and breaks them again at the same width when it saves. Requires Strict line breaks.
