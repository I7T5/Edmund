Open a folder

Open a folder

  1. Choose File > Open, or press Command-O.
  2. Select a folder, then click Open.

The folder opens in one window, with its files listed in the sidebar. You can also drag a folder onto Edmund in the Dock, or in the Finder, Control-click a folder and choose Quick Actions > Open in Edmund.

Switch between files

Click a file in the sidebar to show it in the window. Edits to a file stay when you switch to another, and when you close the window, Edmund asks about each file with unsaved changes.

Files Edmund doesn't edit, such as images and source code, are dimmed. Double-click one to open it in its own app.

To show or hide the sidebar, choose View > Show Sidebar or View > Hide Sidebar, or press Control-Command-S.

Filter the list

Type in the Filter field below the list. The sidebar shows only the files and folders whose names contain what you type, and the folders that hold them. Clear the field to show everything again.

Add a file or folder

  1. Select the folder to add it to. With nothing selected, it goes in the top folder.
  2. Click the Add button (+) below the list, then choose New File or New Folder.

A new file is named Untitled.md and opens in the window; a new folder is named “untitled folder”.

Show hidden files

Control-click the list, then choose Show Hidden Files. Choose it again to hide them.
