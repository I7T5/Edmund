General settings

To open these settings, choose Edmund > Settings, then click General.

Quit when all windows are closed
Edmund quits when you close its last window. Turning this on turns off Reopen windows from last session.
Reopen windows from last session
When Edmund opens, it reopens the documents that were open when it last quit. Turning this on turns off Quit when all windows are closed.
When nothing else is open
What Edmund does when it opens with no documents to show: Create New Document or Do Nothing.
Enable Auto Save with Versions
Saves your changes as you type and keeps earlier versions of each document. When it’s off, you save with File > Save, and macOS still keeps a backup of unsaved changes so they aren’t lost if Edmund quits unexpectedly. On by default.
Manage Version History
Review and delete saved versions to free disk space. See Restore and delete past versions.
Manage Warnings
Turn off warnings you don’t want to see again. See below.

Turn warnings on or off

Click Manage Warnings, then select a warning to stop showing it.

Inconsistent line endings
When you open a document that mixes line-ending styles, for example one edited on both Mac and Windows, Edmund warns you that it will save the document with one style throughout. Select this to stop the warning. To show the warning again, deselect it.
