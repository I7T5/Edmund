Restore and delete past versions

When Enable Auto Save with Versions is on in General settings, macOS saves your changes as you work and keeps earlier versions of each document.

Go back to an earlier version

  • To undo every change since you last saved, choose File > Revert To > Last Saved.
  • To browse earlier versions side by side, choose File > Revert To > Browse All Versions. Select a version, then click Restore.

Delete saved versions

Saved versions take up disk space. To review and delete them across many documents:

  1. Choose Edmund > Settings, click General, then click Manage Version History.
  2. Select the checkboxes next to the versions you want to delete. Select a document or folder to select all of its versions.
  3. To keep recent versions, set the date next to Delete versions before. Only selected versions older than that date are deleted. The date starts at today.
  4. Click Delete.

Deleted versions can’t be recovered. The current version of each document is never deleted.

The list shows documents you’ve opened recently and documents that are open now. To add every document in a folder, click Scan Folder and choose the folder.
