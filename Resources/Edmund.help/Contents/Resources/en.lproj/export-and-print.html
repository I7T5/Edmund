Export, copy, and print

Export a document

Choose File > Export To, then choose a format. The original .md file doesn’t change.

PDF
The document as it looks in Read.
HTML
A web page with the theme’s styles.
Plain Text
The text with the Markdown characters removed.
Rich Text Format
Formatted text that word processors such as Pages and TextEdit can open.
Markdown with Embedded Images
One .md file with every local image stored inside it, so you can send it without its image folder.

Images from the web are left out of exports when Block external images is on in Advanced settings.

Copy formatted text

Select text, then choose Edit > Copy As > Rich Text to paste it with formatting into another app, or Edit > Copy As > Plain Text to paste it without Markdown characters.

Print

Choose File > Print, or press Command-P. To change the paper size or orientation, choose File > Page Setup first. Line numbers aren’t printed.
