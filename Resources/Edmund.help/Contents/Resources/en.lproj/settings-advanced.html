Advanced settings

To open these settings, choose Edmund > Settings, then click Advanced.

Software updates

Automatically check for updates
Edmund checks for a new version from time to time and asks before installing it. To check now, choose Edmund > Check for Updates.

Privacy & Security

Block external images
Images with a web address (https://…) aren’t loaded in Edit, Read, or exports. Loading one can tell its website that you opened the document, and when. Images stored on your Mac still show. On by default.

Diagnostics

Edmund doesn’t send crash reports or logs anywhere on its own. Logs stay on your Mac until you attach them to a report.

Ask to report crashes on GitHub
After Edmund quits unexpectedly, the next time it opens it offers to start a bug report on GitHub with the crash details filled in. You review the report before you submit it.
Save diagnostic logs
Edmund writes a log file each day. Clear logs after sets how long they’re kept. To find the files, click Show in Finder. Attach them to a bug report to help find the problem.
Verbose editor tracing
Records every keystroke and insertion point move in the logs. Turn it on only while you reproduce an editor bug, then turn it off. Requires Save diagnostic logs.
